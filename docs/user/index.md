# kiryl user guide

kiryl is a Python fuzz-testing tool under development. There is no released
package or usable fuzzing command yet. Installation and usage instructions will
appear here as those features become available.

Follow [Issue #1](https://github.com/HayaoSuzuki/kiryl/issues/1) for the initial
research scope. For development, use the
[repository](https://github.com/HayaoSuzuki/kiryl) and its developer entry point.
