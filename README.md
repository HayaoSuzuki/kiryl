# kiryl

Fuzz testing tools for Python, implemented primarily in Rust.

This repository currently contains development and CI configuration in
preparation for [Issue #1](https://github.com/HayaoSuzuki/kiryl/issues/1).
Fuzzing functionality and the engine choice have not been implemented.
Atheris and other engines remain candidates for evaluation.

Read [the user guide](docs/user/index.md) for availability and usage.
Developers and AI agents should start with [the development guide](docs/development/index.md)
and its [OKF catalog](docs/development/knowledge/index.md).
