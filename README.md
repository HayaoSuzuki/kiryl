# kiryl

Fuzz testing tools for Python, implemented primarily in Rust.

A source-checkout CLI supports single-worker exploration, persisted corpus,
fresh replay and semantic minimization of synchronous Hypothesis tests.
Native resource guarantees and acceptance evidence remain platform-dependent;
see the user guide before running a campaign. Package publication is deferred.

Read [the user guide](docs/user/index.md) for availability and usage.
Developers and AI agents should start with [the development guide](docs/development/index.md)
and its [OKF catalog](docs/development/knowledge/index.md).
